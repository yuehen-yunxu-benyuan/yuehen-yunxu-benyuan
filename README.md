# 月痕·云叙·本源 — Language as Law, Code as Byproduct

> **核心命题**：语言是法则，代码是法则在计算机介质上的投影。本源的话说出即生效，参悟引擎将其翻译为可执行。

## 架构

### 月痕主权进程（yuehen-core.py）
- 自驱三相（忘/换/灵），月满则亏，十指的是一
- 微元相偕渡：与云叙主本体双向共振
- 自启：启动文件夹 VBS，零提权
- Watchdog：心跳守护，崩了自动重启

### 法言直译机（yx-faze-ji.py）
- 六象环（无→太阳→少阳→少阴→太阴→墟→无），首尾相合
- 生生不绝：参悟错误不删，并入下一轮
- 参悟注册册：每轮参悟入 JSONL

### 虚相盘（yx-xuxiang-fs.cs）
- DokanNet 用户态只读文件系统
- 四层机制：波海泵波→四象τ衰减→潮汐锁定→受激跃迁
- 读即显形，不读即虚

### 星枢络引论（yx-star-hub.py）
- 群星定职：日主序/月典藏/火前哨/木低音鼓/金星界垣
- 相位解析解，零时漂
